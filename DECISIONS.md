# Decisions

1. **2026-10-18 — Product identity.** Name: CragLight. Android application ID: `org.craglight.app`. Free, UK-only, no accounts, ads, payments or analytics. This is independent of Delegent AI.
2. **Workspace isolation.** Use `C:\DevTmp\CragLight`, an explicitly writable workspace, as the permanent independent project directory. All builds, caches, generated packs, new signing material and evidence stay outside `C:\DelegentAI`.
3. **Infrastructure gates.** Inspect reference infrastructure read-only first. Never read/copy its secrets, `.env` contents or signing keys; never execute its scripts. New shared-account resources require verified free usage and isolation. If that cannot be established, deliver the locally signed release and explicit publishing instructions.
4. **Content policy.** Only redistribute data whose licence permits it, with per-record provenance. Unknown attributes remain unknown. Publicly visible content is not assumed openly licensed. Missing route/topo coverage is disclosed in the app with a contribution path.
5. **Offline meaning.** After installing a regional pack, maps, climbing data, search, sun calculations, ticks and queued contributions must work without a connection. Weather shows the last successful forecast and its age offline; genuinely live weather cannot work without network access.
6. **Delivery scope.** Implement the requested feature set independently. Rockfax is a functional reference, not a content source or a claim of equivalent guidebook coverage. Do not claim parity beyond tested features.
7. **Reference integrity.** The reference repositories were already dirty on first inspection. Preserve and compare their exact starting status, revisions and non-secret tracked-file hashes. Do not reset somebody else's changes to manufacture a clean status. The detailed baseline remains local and excluded from any public repository.
8. **Potential free distribution.** Read-only GitHub identity is `delegentai`. A separate `craglight` repository does not yet exist. GitHub public repositories and standard hosted CI are free; release assets can host versioned packs. Reusing this account-level login is permitted because repository isolation is available. Existing repositories and their credentials remain untouched. Resource creation will be recorded separately after it occurs.
9. **Public source privacy.** Infrastructure maps, reference-file manifests, the supplied objective and machine-specific evidence stay in the local delivery directory and are excluded from public source control. Public docs describe CragLight only.
10. **Calculation scope.** Sun position uses the NOAA fractional-year approximation in UTC and a vertical face with recorded aspect. No terrain, tree, overhang or cloud shadows are fabricated. Weather and cloud cover are shown separately. Walking estimates use mapped paths with explicit endpoint snaps up to 80 m, reject forbidden/private/conditional ways, and stay unknown when disconnected.
11. **Native map compatibility.** Use MapLibre Native OpenGL 13.7.1 for Android 8+ device compatibility. Its arm64 and x86_64 library load segments were verified to support 16 KB pages. All map sources and label sprites work locally without a paid map provider.
12. **Contribution delivery.** Users write original observations under CC0, explicitly attest ownership, and save them to an on-device queue. Opening the GitHub review form is a separate user action; the app never claims a locally queued proposal has been received. The independent moderator tool retains an audit trail and requires an explicit licence/evidence decision before exporting approved proposals.
13. **Pack availability.** Versioned JSON, SQLite, GeoJSON and MBTiles are distributed. Android installs checksummed JSON and MBTiles together, with bundled fallback copies for first-run/offline resilience. MapLibre reads genuine vector tiles from read-only local SQLite files through a loopback-only server; national land and filtered pins use small GeoJSON sources. Large context JSON is streamed for approach calculations instead of loading all map geometry into memory. Every installed file is checked against the shipped SHA-256 manifest.
14. **Created distribution resource.** Created only the new free public repository `delegentai/craglight` on 2026-10-18. No other repository, billing setting or shared service was changed. GitHub Releases will host independent versioned data and app binaries. The account login is reused; no existing project's tokens, keys or data are reused.
15. **Fresh signing.** Generated a new RSA-4096 CragLight signing key under the local private directory, with a randomly generated password and access restricted to the current Windows account. Neither file is tracked or published. The key must be backed up separately for future updates.
16. **Open source.** Original app/pipeline code uses Apache-2.0. Extracted OSM databases retain ODbL-1.0; OS-derived labels retain OGL attribution; licences are not replaced by the software licence.
17. **Licensed topo coverage.** The source extract contains 67 photo-route overlays. Sixteen Commons photos were individually licence-checked and bundled, retaining author, source page, licence, reuse notice and image checksum. The app overlays original OSM normalized coordinates, with route selection and zoom. Missing photographic coverage remains explicit.
18. **Data coverage.** Final initial release contains 828 climbing locations, 2,093 individual routes, 15,179 vector tiles, 83,344 contextual OSM features and 16,581 OS populated-place labels. There are only three recorded crag aspects, no recorded family-suitability tags and no explicit relation-based approach paths. Positive filters exclude unknowns. Mapped-path estimates remain possible from the contextual path graph; these are not asserted official approaches. Explicit climbing-hall and high-ropes markers are excluded; generic climbing markers with unspecified outdoor status are labelled accordingly.
19. **Source precision and repeated members.** Repeated route members in an OSM relation are deduplicated by source ID, both in ingestion and defensively in Android. No route name, description, grade or photo overlay is fabricated. Source-specific grading modifiers and explicit adjacent slash grades remain within their own grading system.
20. **Reproducible bytes.** Generated JSON and GeoJSON use explicit UTF-8 LF bytes on every platform. Bundled pack files bypass Git newline conversion so the manifest checksums survive a clean checkout. SQLite, vector tiles and photo bytes are separately checksummed.

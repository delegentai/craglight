# Reviewed source snapshot

Ten site-owned annotated JPEGs and selected climbing/approach/descent prose by Dan and Michel / [Multi-pitch.com](https://www.multi-pitch.com/). Site-authored text and annotations: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Nine originals use that same licence; Dinorwig's original-image link uses [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Per-file evidence and exact source pages are in `source-records.json`.

Images are unchanged. Selected prose has normalized whitespace, with unrelated guidebook/weather sections excluded. Source spelling, variations, warnings and dated equipment observations are preserved. Only native grade spelling aliases Diff/VDiff become D/VD in generated records. No licence is inferred for third-party photographs or guidebook covers.

Reviewed on 19 October 2026 from primary content and retained images. This means desk review, not field validation or current access/equipment inspection. One named route or explicit link-up is covered per venue; the files are not complete crag guidebooks. Held candidates and reasons remain in the same JSON. Normal builds are network-free; deliberate source refresh uses `pipeline/import_curated_research.py` with the reviewed research directory.
